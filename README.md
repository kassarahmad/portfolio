# Ahmad Kassar: engineering portfolio

The source of my portfolio site and the projects it presents. Everything here is built to be run and checked, not just looked at.

| Path | What it is | Status |
| --- | --- | --- |
| [`site/`](site) | The portfolio in English, Italian, French and Arabic (RTL): static pages generated by a small Node script, no framework, strict CSP, contact form | Built and tested; ready for Netlify at ahmad-kassar.netlify.app |
| [`projects/slotbook/`](projects/slotbook) | Appointment booking API and web client on PostgreSQL | Built and tested |
| [`projects/hostwatch/`](projects/hostwatch) | Linux server monitoring: Python agent, alerting server, live dashboard | Built, tested, run against a real VM |
| [`projects/shipyard/`](projects/shipyard) | Production deployment on AWS EC2: Compose, Caddy, backups, CI/CD | Configuration and scripts tested; not deployed |
| [`.github/workflows/`](.github/workflows) | CI, release and deploy pipelines | Written and parsed; not yet run on GitHub |

Existing work (the Hyperlean RAG assistant, Buon Gusto, Prontix, Stepvia) lives in other places and is documented here as case studies; this repository doesn't contain their code.

## Run it

```bash
# Portfolio site
cd site && npm run build && npm run serve          # http://127.0.0.1:8080

# Slotbook (needs PostgreSQL 14+ or Docker)
cd projects/slotbook && cp .env.example .env && docker compose up --build

# Hostwatch
cd projects/hostwatch/server && cp .env.example .env   # fill secrets, see README
npm run dev
python3 ../agent/hostwatch_agent.py --once               # one real sample from this machine

# Everything at once (needs PostgreSQL and Playwright)
PGHOST=127.0.0.1 PGUSER=postgres PGPASSWORD=... scripts/verify-all.sh
```

Each project's README has full setup, configuration, security notes, limitations and troubleshooting.

## Requirements

Node.js 22.12+, Python 3.9+, PostgreSQL 14+ (with contrib), Docker with Compose v2 for the container setups. The Node projects have **no runtime dependencies**; development tools (ESLint, Prettier, TypeScript, Playwright) are pinned in the scripts and CI.
